Dofuxya - version 1.2

Organise les fenetres Dofus 3 et Dofus Retro d'une equipe multicompte.
L'outil n'agit que sur les fenetres : il n'envoie aucune touche ni aucun clic au jeu.

Compiler
1. Quitte la version en cours (clic droit sur son icone dans la zone de notification > Quitter).
2. Double-clique sur build.bat (rien a installer). Dofuxya.exe apparait dans ce dossier.
   Si le suivi du tour ne peut pas etre compile sur le poste, build.bat compile sans et l'indique ;
   le detail est dans build-suivi.log.

Fonctions
- Detection des seules fenetres Dofus ouvertes, mise a jour instantanee.
- Ordre d'initiative, ou ordre manuel en faisant glisser le numero d'une carte.
- Fenetres renommees avec le nom du personnage, icone de classe (integree a l'executable ;
  un dossier "icones" a cote de l'exe permet de remplacer une icone).
- Raccourcis clavier ou souris : fenetre suivante, precedente, personnage principal,
  et un raccourci par personnage. Portee : dans Dofus seulement, ou partout.
- Bouton "Grouper l'equipe" (onglet Equipe) : amene le personnage principal devant et copie
  les commandes /invite des autres personnages ; colle-les dans le chat (Ctrl + V, Entree).
- Barre des taches rangee dans l'ordre du tour.
- Mini-barre flottante, horizontale ou verticale.
- Dofus Retro : suivi du tour par les notifications Windows, agrandissement automatique.
- Zone de notification : la croix masque la fenetre, l'outil reste actif.
- Lancement avec Windows (option).

Suivi du tour sur Retro, a regler une fois
1) dans le jeu : activer les notifications en arriere-plan ;
2) dans Windows : laisser les notifications du jeu activees ;
3) Parametres > Confidentialite et securite > Notifications : autoriser les applications
   a acceder aux notifications.

Installateur et mises a jour (pour l'auteur)
Les versions sont publiees sur GitHub (Altaryxa/dofuxya-app) :
  1. pousser un tag vX.Y.Z (ex. git tag v1.2.1 puis git push origin v1.2.1) ;
  2. GitHub compile l'outil, fabrique l'installateur et publie la version (onglet Actions) ;
  3. sous 15 minutes environ, https://dofuxya.com/tool propose la nouvelle version.
Lien de telechargement, qui ne change jamais : https://dofuxya.com/tool/download
Au lancement, avant d'ouvrir sa fenetre, l'outil lit https://dofuxya.com/tool/version.txt (adresse
dans mise-a-jour.txt). Si une nouvelle version existe, il la telecharge, verifie son empreinte,
l'installe en silence et s'ouvre directement a jour. Sans reseau, il s'ouvre normalement apres
quelques secondes au plus. Les mises a jour sont obligatoires.
Les joueurs installent avec Dofuxya-Setup-x.y.z.exe (sans droits administrateur).
Pour fabriquer l'installateur sur son poste : Inno Setup 6 ou 7 (gratuit, https://jrsoftware.org/isdl.php),
puis build.bat et publier.bat (dossier "publication").

Donnees : %AppData%\Dofuxya (reglages, initiatives, erreurs.txt en cas de plantage).
Outil de fan, non affilie a Ankama. Dofus est une marque d'Ankama.
